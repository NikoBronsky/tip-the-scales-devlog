# Tip the Scales - development log

Entry for the 2026 Epic AI MegaJam, made with Unreal Engine 5.9. Team: One Man Raft.
One human directed the game. AI agents did the production: design drafts, code, pictures, sound, builds.

- `DEVLOG.md` - the development log, written entry by entry during the jam. Start here.
- `Docs/briefs/` - the task briefs that the orchestrator agent wrote for the executor agents (our prompts), and the reports of the executors.
- `Docs/decisions/` - every decision of the director, with his own words quoted (in Russian, his language).
- `CLAUDE.md` - the contract that every agent reads first (in Russian).

This repository holds documents only. The project repository with the source code and the full version history is
private and is available to Epic Games on request, as the Official Rules provide. In paths, the name of the local
user folder is replaced with `<user>`.
