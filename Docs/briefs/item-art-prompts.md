# Shop item art: the prompts sent to Codex image generation

Tool: Codex CLI (`codex exec`, sandbox workspace-write) on the director's ChatGPT plan, 13.11.2026.
One call per sheet. Each call gets the four accepted fish pictures as style references (`ref_*.png`).
Output: sheets of six items, 1536x1024, on flat magenta. `Tools/item_cut.py` cuts the items out.
