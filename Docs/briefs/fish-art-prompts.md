# Fish art: the prompts sent to Codex image generation

Tool: Codex CLI (`codex exec`, sandbox workspace-write) on the director's ChatGPT plan, 13.11.2026.
Four calls. The first made four sample pictures; the director accepted the style; the other three calls got the four samples as reference files (`ref_*.png`).
Output: 15 pictures, 1536x1024, one fish each on flat magenta. The cut-out and the atlas are made by `Tools/fish_cut.py`.

Use your built-in image generation tool to create FOUR images and save them in the current working directory as sprat.png, mackerel.png, sea_bass.png, gold_sunfish.png. (3) sea bass: larger olive-grey fish with a spiny dorsal fin and dark spots along the side. (4) gold sunfish: tall round ocean sunfish (mola) in shining gold with warm orange fins and small pale spots, it must look special and precious. After saving, print the file names and pixel sizes. Do not create any other files.
