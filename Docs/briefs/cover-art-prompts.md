# Cover of the game page: the prompts sent to Codex image generation

Made on 14.11.2026 23:52 - 15.11.2026 00:02 with Codex image generation on the director's ChatGPT plan, the same tool
and style as the fish and shop pictures. Five `codex exec` calls, one picture each, 1536x1024. The four first fish
pictures (sprat, mackerel, sea bass, gold sunfish) were in the working directory as style references.
The cover is used on the itch.io page only. It is not in the game.

After generation our script (`cover_compose.py`, Pillow) crops the central 1290x1024 area and scales it to 1260x1000
and 630x500, the shape itch.io asks for. For the variants without text the script sets the title in Roboto Black
from the engine's font folder.
